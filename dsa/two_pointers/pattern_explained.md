# Two Pointers

## How to identify

- You are given a contiguous set of values, and you need to find/compute a 'target' value

## Relevant problems

- 2Sum
- 2Sum Sorted
- 3Sum
- Max Area

## Tips

- Brute force is usually 2 loops
- Almost always contains this condition

```javascript
while (left < right)
while (start <= end)
while (low < end)
```
